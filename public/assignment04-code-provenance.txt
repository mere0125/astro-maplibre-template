4. Existing project work and data

The fourteen analysed parcels and their 2022 vegetation measurements
come from the retained Assignment 3 GeoPackage, raster inputs, analysis
script, and parcel-level audit table. Their 1996 and 2018 interpretation
fields come from the retained Assignment 2 temporal-vacancy dataset.

The East New York screening context uses the original 254 matched lots
from the earlier assignments. The citywide context uses PLUTO and
MapPLUTO release 26v2, filtering LandUse code 11, Vacant Land.

The citywide administrative count is 24,663 records. Of these, 423 have
null geometry and 27 have empty geometry; 24,213 nonempty features can
be drawn. The record count and mapped-feature count are kept distinct.

Primary data sources are NYC Department of City Planning PLUTO and
MapPLUTO, NYC Office of Technology and Innovation archival aerial
imagery from 1996 and 2018, and USDA NAIP imagery from 2022. The 2026
vacant-land status is an administrative classification, not an aerial
image observation from that year.

5. OpenAI Codex contribution

OpenAI Codex was used in this collaboration to generate and revise data
preparation code, Astro page code, HTML, CSS, TypeScript and JavaScript,
map interactions, explanatory text, and debugging changes. It also
assisted with auditing the source files, recomputing vegetation metrics,
checking the interface, and preparing publication files.

This contribution includes implementation, not only conceptual guidance.
The code should not be described as written entirely by Mere without
assistance. Mere's stated project direction and design preferences guided
the topic, visual style, and requested revisions.

The project was developed using retained GIS data and reproducible
processing. The website itself is rendered by Astro and MapLibre, rather
than being an interactive export generated directly by QGIS.

The surface-folio extension was developed with the same Codex
implementation assistance. It adds the third navigation choice, the
paired evidence composition, common-scale specimen selection, and the
field-register download. scripts/prepare_assignment04_specimens.py
derives fourteen transparent parcel cutouts from the retained 2022 RGB
raster and current parcel geometries. It produces images under
public/images/assignment04/specimens/, metadata in
public/data/assignment04/specimens.json, and the fourteen-record
public/data/assignment04/field_register.csv.

All cutouts use a common 300-foot square extent in EPSG:2263, with grid
north up. Actual RGB pixels are bilinearly resampled for display and
masked to each current parcel boundary. No vegetation is generated or
recoloured. The original NDVI measurements remain unchanged. The paired
context excerpts retain their separate common extent of 450 feet.

6. Understanding and interpretation

The presenter should be able to explain the map object, data layers,
coordinate conversion, scale changes, filters, selected-feature state,
image comparisons, and the relationship between a GeoJSON property and
its visible colour or symbol. Source disclosure does not substitute for
understanding or revising the code.

The fourteen lots form a purposive pilot sample. The NDVI threshold of
0.20 is an exploratory measure of spectral vegetation response. The
interface does not establish continuous vacancy, forest status,
biodiversity, public access, or a causal effect of vacancy duration.

The folio's opening pair, 492 Glenmore Avenue and 943 Dumont Avenue, was
deliberately chosen to illustrate contrasting 2022 responses, 92.3 and
0.3 percent, within the same current vacant classification and the same
open-in-1996-and-2018 group. Their reported areas are 5000 and 5400 square
feet. This is not a matched or controlled study. The two full historical
groups have median responses of 63.1 percent (eight parcels open at both
dates) and 63.6 percent (six parcels built in 1996 and open in 2018). The
field register records image and administrative evidence, not completed
field visits.

This text records the actual code origins and assistance. It does not
claim that the instructor has approved every form of assistance used.
